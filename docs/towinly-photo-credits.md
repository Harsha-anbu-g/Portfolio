# Why Towinly page: photo credits

Every photo on `/towinly/` is from **Pexels**, used under the
[Pexels licence](https://www.pexels.com/license/): free to use, attribution not required.
Recorded here anyway so each file can be traced to its source. Added 2026-10-29.

Rules the set follows (from Towinly's own `marketing/instagram/assets/photos/PHOTO-CREDITS.md`):
no face appears next to copy that says "you" or next to a number; no photo is captioned as a
Towinly member; nothing shows an elder in a bad light. The set is hands, rooms, objects and
people seen from behind. Rebuild with `bash scripts/towinly-photos.sh`.
